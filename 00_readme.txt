#DATA
MRI_RNA_Code should be in your working directory. Make sure to cd into this directory and activate
    the conda environment before running scripts.
The folder MRI_RNA_Data contains all persistent data (i.e. raw inputs).
MRI_RNA_Scratch contains all intermediaries generated during the pipeline.
You will need to set the paths for the latter two folders in 01_environment.yml

ROSMAP RNAseq data comes from https://www.synapse.org/Synapse:syn26720675 but the folder is 
    renamed to MRI_RNA_Data/ROSMAP_RNA for clarity.
Your MRIs are expected to be in MRI_RNA_Data/BIDS with the format: sub-00000001/ses-0/anat/T1.nii.gz
    where sub-XXXXXXXX is the subject ID and ses-X is the session number. In our data, re-runs get names
    like SCANa.T1w.nii.gz if the original is SCAN.T1w.nii.gz - 04 handles this by taking the scan with the
    highest alphabetical value.
MRI_RNA_Data/ROSMAP_MRI should have rosmapAD_data_imaging_confounds_ageScan.csv (columns: projid,mri_date,age_scan,protocol),
    mri_metadata.csv (columns: Subject,Session,Protocol_Date,Scan_Type,Modality,MagneticFieldStrength, etc),
    and rosmapAD_data_phenotypes_masterBrainSide (columns: projid, study, master_brain_side)

#REPRODUCTION ISSUES / THINGS TO CHANGE MANUALLY:
In 04_Freesurfer_MRI_Processing.py, you will need to change the lines that load Freesurfer to 
    whatever is appropriate for your system. You may also need to tweak the slurm submission info
    based on whatever requirements your system has (max job length, etc.). The batch_size variable
    is how many recon_all jobs are run in parallel - edit based on the amount of cores and RAM
    available (even if you have a bunch of CPUs memory can cause problems).

#SCRIPT-BY-SCRIPT NOTES
01: defines the environment, needs manual path setting
02: gets the count matrices in the right shape, normalizes and batch corrects them
03: makes supplemental PCAs to show batch correction
04: makes slurm scripts to run recon-all on the raw scans. cd into MRI_RNA_Code, activate the conda environment, and run from terminal
04b: bash code to submit the jobs
04c: repeat of 04 for any that failed for whatever reason - make sure to wait until everything from the previous step is done running!
04d: equivalent of 04b to submit the scripts generated by 04c
